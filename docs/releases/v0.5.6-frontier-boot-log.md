# Release plan: v0.5.6 (frontier backend boot log)

Target: release server (self-hosted runner `openlens-release`).
Mechanism: tag `v0.5.6` triggers
[.github/workflows/release.yml](../../.github/workflows/release.yml).

## What's in this release

- **Ops visibility**: every crawler worker logs one line at boot —
  `frontier backend=<postgres|redis> store=<StoreClass>
  mirror=<on|off>` — so Dozzle shows which frontier path is live
  without guessing. No behavior change; logging only.
- Regression test pins the log line on the default path.

## Pre-release checklist

- [ ] `git status` clean except this plan file.
- [ ] No new env vars; no config changes; no `-v` volume wipes.

## Release steps

1. Tag `v0.5.6` and push `main` + tag (tags never move).
2. Watch the `release` workflow (`concurrency: release-production`).
3. Gates: `/healthz`, frontier status, search probe, both frontends.

# Release plan: v1.1.14 (lightweight stack, CVE fix)

Target: release server (self-hosted runner `openlens-release`).
Mechanism: tag `v1.1.14` triggers
[.github/workflows/release.yml](../../.github/workflows/release.yml)
(full stack), then a manual
[.github/workflows/release-lightweight.yml](../../.github/workflows/release-lightweight.yml)
dispatch downgrades the server to the lightweight stack. The tag must
land first: both workflows share the `release-production`
concurrency group, so the downgrade queues behind the full deploy
instead of racing it.

## What's in this release

- **Lightweight stack** (`docker-compose-lightweight.yml` at the repo
  root): backend (single uvicorn worker), frontend, Postgres
  (`max_connections=50`, `shared_buffers=128MB`), one Redis
  (`maxmemory 64mb`), one store-backed crawler. Kafka, ClickHouse,
  redis-frontier, replica, pgAdmin, kafka-ui, dozzle, and
  crawler-backoff are dropped; admin-frontend is opt-in via
  `--profile admin`. Budget ≈ 2.9G / ~3.25 CPU inside 4G/4CPU.
- **Lean backend image** (`deploy/local/Dockerfile.backend-lightweight`):
  base deps only, no `[kafka,analytics]` extras. Drivers lazy-import
  and every Kafka/ClickHouse call site degrades cleanly without them,
  so the image skips import weight and broker reconnect threads.
- **Graceful downgrade workflow** (`release-lightweight`): detects the
  current fleet, drains crawlers, tears the full stack down with plain
  `down` (never `-v`), and starts the lightweight stack under the SAME
  project name (`-p openlens-local`) so `pgdata`/`redis-data`/
  `openlens-data` are reused, not recreated. Rollback is a plain
  `release` run.
- **CVE fix**: `opentelemetry-api 1.45.1 → 1.45.2` (CVE-2026-126360)
  in `uv.lock`; pip-audit clean.

## Operator notes

- Search is briefly unavailable during the swap (~1 min: old-down to
  new-backend-healthy). Run the downgrade dispatch at a quiet time.
- No `-v` anywhere near the server volumes; heavy-only volumes
  (kafka1-data, clickhouse-data, replica-data, ...) stay on disk.
- Bump: `pyproject.toml` 1.1.13 → 1.1.14.

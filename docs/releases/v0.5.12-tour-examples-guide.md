# Release plan: v0.5.12 (tour runs the demo itself + user guide)

Target: release server (self-hosted runner `openlens-release`).
Mechanism: tag `v0.5.12` triggers
[.github/workflows/release.yml](../../.github/workflows/release.yml).

## What's in this release

- **Tour example actions**: the search gate runs an example search
  for real, the chat gate opens AI chat, and the chat-view step asks
  an example question through the real chat pipeline — the tour no
  longer dead-ends when the user presses Next without acting.
- **Tour buttons** move to the `ui/Button` primitive (`Button`
  gains a `ref` prop for per-step focus).
- **ChatView** accepts a one-shot `exampleQuestion` (consumed
  exactly once, StrictMode-safe).
- **Wiki**: new step-by-step Search and Admin Guide with prod
  screenshots under `docs/wiki/assets/` (`admin-config.png` still
  to be captured — the guide notes its placement).

## Pre-release checklist

- [ ] `git status` shows only the files below (plus this plan).
- [ ] No env/config changes; no `-v` volume wipes.
- [ ] Frontend gates green (308 passed, eslint/prettier/build).

## Release steps

1. Tag `v0.5.12` and push `main` + tag (tags never move).
2. Watch the `release` workflow (`concurrency: release-production`).
3. Gates: `/healthz`, frontier status, search probe, both frontends.

## Post-deploy verification

- Take a tour on prod: example search runs, chat opens, the
  example question answers with citations.
- Guide renders with all 7 images; capture `admin-config.png`
  when convenient.

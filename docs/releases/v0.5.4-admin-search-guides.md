# Release plan: v0.5.4 (admin search analytics, config guides)

Target: release server (self-hosted runner `openlens-release`).
Mechanism: tag `v0.5.4` triggers
[.github/workflows/release.yml](../../.github/workflows/release.yml).

## What's in this release

- **Admin Analytics tab**: new search-traffic section. `Searches
  served` and `No-result searches` KPI cards with prior-period
  deltas, plus a sortable `Searches by mode` breakdown — all read
  from the existing `search.served` analytics events. No backend
  change.
- **Admin config editors**: fixed the transparent-textarea overlay
  (opaque background blanked every doc) and added a collapsible
  per-doc field guide (models, providers, ranking, query, plugins,
  indexing).

## Pre-release checklist

- [ ] `git status` clean except this plan file.
- [ ] No new env vars; server-side `release.env` needs no changes.
- [ ] No `-v` volume wipes. UI-only change; no data migration.

## Release steps

1. Tag `v0.5.4` and push `main` + tag (tags never move).
2. Watch the `release` workflow (`concurrency: release-production`).
3. Gates: `/healthz`, frontier status, search probe, both frontends.

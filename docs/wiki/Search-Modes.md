# Search Modes (customers)

The mode selector next to the search box narrows the index by intent.
The backend pre-filters inside retrieval, so result counts stay exact.

| Mode | What it does |
|---|---|
| **Default** | Whole index, ranked for general relevance. |
| **News** | News sources only; same-event articles group into stories with [Perspectives](Perspectives). |
| **Shopping** | Product pages; price, rating, and availability surface on the card. Sponsored placements are labelled and can be filtered. |
| **Travel** | Hotels, places, and food with location, distance, and facilities. |
| **Child-safe** | Age-appropriate filtering: adult, unsafe, and otherwise unsuitable content is removed before ranking. |

The search page may suggest a mode for your query ("Try news
mode") — one click re-runs the search in it.

Child-safe, shopping, and travel filters are data-driven: a result
appears in a mode only when the crawl classified it there, so a weak
category shows fewer results rather than wrong ones.

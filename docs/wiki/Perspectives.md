# Perspectives (customers)

Where several indexed sources cover the same story, OpenLens groups
them into one **Different perspectives** section above the results.

Each story view shows:

- **The claim** — the representative factual statement.
- **Stances** — which sources back it, contradict it, or take no
  position, each with a short evidence quote. Stances come from a
  keyword heuristic and are labelled as such: a reading aid, not a
  verdict.
- **Multiple sources** badge when members come from different sites.
- **Coverage gap** notes when no indexed source takes one side
  ("no refuting source in this cluster").
- **Trust caveats** when a member carries warnings or a low
  credibility signal.

Perspectives never change ranking — they are assembled from the
already-ranked page. Single-source results render as plain cards
with no group chrome. The same block appears in [AI Mode](AI-Mode)
answers and in the admin-blind search UI.

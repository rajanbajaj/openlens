# Getting Started (customers)

## First search in 2 minutes

1. Open the search page (port `3000` on a local stack).
2. Type in the big box — suggestions appear as you type.
3. Press **Search**. Results show title, snippet, source badge, and
   score breakdown; some carry trust warnings or key claims.

No account, no tracking profile. Recent searches stay in your own
browser only.

## Reading a result

- **Badges** explain provenance: which provider indexed the page,
  paid placements (`Sponsored`), opinion vs reporting.
- **Why this result**: expandable reasons show which filters passed
  and how scoring weighed in.
- **Warnings** are visually distinct and expandable: trust problems,
  mismatches, stale copies.
- **Key claims** (news): the concrete factual spans the story makes.
